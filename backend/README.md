# ShopForge Backend

ShopForge is an AI-powered digital catalog platform for local retailers.

This backend provides the APIs for users, stores, categories, and products.

## Tech Stack

- Python
- FastAPI
- SQLAlchemy
- PostgreSQL
- Supabase
- JWT Authentication
- Argon2 Password Hashing
